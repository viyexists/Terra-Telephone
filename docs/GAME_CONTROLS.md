# Game controls
`W` `A` `S` `D` - Move the player<br>
`Escape` or `Q` - Pause the game<br>
`F` - Switch slot 1 and slot 2 magic<br>
`Tab` - Show Inventory<br>
`E` - Interact<br>
`Left Mouse Button` - Tomato attack<br>
`Right Mouse Button` or `V` - Cast slot 1 magic<br>
